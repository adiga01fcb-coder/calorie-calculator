# Калькулятор калорий

Локальная одностраничная страница: калорийность и БЖУ продуктов и блюд, дневник питания. Опубликована на GitHub Pages: https://adiga01fcb-coder.github.io/calorie-calculator/

## Как открыть

Откройте `index.html` в браузере: двойной щелчок или перетащите файл в окно браузера. Интернет, сервер и сборка не нужны, внешних библиотек и CDN нет.

## Что умеет

- Поиск продукта с автоподсказками. Учитываются регистр, ё/е, падежи («сколько калорий в яйце») и опечатки («кефр»). Подсказки выбираются стрелками ↑ ↓ и Enter, мышью или касанием.
- Количество задаётся в граммах или порциях. У каждого продукта есть типичная порция: 1 яйцо = 55 г, Биг Мак = 219 г и т. д.
- Показываются калории, белки, жиры и углеводы для введённого количества и на 100 г.
- Дневник питания: завтрак, обед, ужин, перекус; итоги за день, цель по калориям, переключение дат, удаление записей, очистка дня. Хранится в `localStorage` браузера и переживает перезагрузку.
- Таблица калорийности всех продуктов с фильтром по названию и категории.
- SEO-разделы «Сколько калорий в …» с якорями, FAQ, meta description, robots, Open Graph, JSON-LD (WebApplication + FAQPage).

## Данные и источники

Значения приблизительные и усреднённые, на 100 г съедобной части.

- **USDA FoodData Central, SR Legacy** (апрель 2018, общественное достояние). Строка `U:` в `tools/spec`; значения подставляются автоматически по точному названию продукта в USDA. В USDA углеводы считаются «по разности» и включают клетчатку.
- **Российские таблицы химического состава** (Скурихин, Тутельян) и типовые рецептурные значения для готовых блюд. Строка `R:ккал/Б/Ж/У` в `tools/spec`.

Чтобы добавить продукт, допишите строку в нужный `tools/spec/*.txt` и выполните:

```
python3 tools/resolve.py      # пересобрать data/products.js
python3 tools/gen-seo.py      # обновить цифры в SEO-разделах
node tests/run-all.js         # проверить
```

## Тесты

- `node tests/run-all.js` — тесты без браузера:
  - данные: не меньше 500 позиций, категории, проверка ккал ≈ 4·Б + 9·Ж + 4·У, дубли, порции;
  - расчёт, поиск и ранжирование подсказок, дневник с имитацией localStorage;
  - статическая проверка HTML и SEO.
- `node tests/browser-check.js [--screenshots]` — проверка в headless Chrome без звука. Нужны Chrome и `puppeteer-core`: `npm i puppeteer-core` в любой папке, путь передаётся через `NODE_PATH`. С флагом `--screenshots` скрипт обновляет снимки в `screenshots/`.

## Реклама (Google AdSense)

Сейчас на странице только заглушки, внешний код не загружается. Чтобы включить рекламу:

1. В `index.html` найдите закомментированный блок `adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX`. Раскомментируйте его и замените `ca-pub-XXXXXXXXXXXXXXXX` своим идентификатором издателя.
2. Каждый `<div class="ad-slot" … data-ad-slot="XXXXXXXXXX">` (их три) замените кодом рекламного блока из кабинета AdSense: `<ins class="adsbygoogle" …>`, указав свои `data-ad-client` и `data-ad-slot`.
3. Канонический адрес (`<link rel="canonical">`) уже указан: https://adiga01fcb-coder.github.io/calorie-calculator/

## Ежедневное автопополнение базы

`tools/auto/daily_add.py` раз в день добавляет 50 продуктов из очереди `tools/auto/pool.tsv`: 900 кандидатов из USDA FoodData Central SR Legacy, это общественное достояние. Значения на 100 г берутся из USDA без изменений, названия переведены на русский. У каждого продукта сохраняется fdc_id: строка `# fdc_id …` в `tools/spec/14-auto-usda.txt` и журнал `tools/auto/added.tsv`. Проверить значения можно на `https://fdc.nal.usda.gov/food-details/<fdc_id>/nutrients`.

Скрипт делает следующее:
- отсеивает дубли по названию, slug, ID и описанию USDA;
- проверяет правдоподобие: 0–900 ккал, Б+Ж+У ≤ 100 г, соответствие ккал и БЖУ по Этуотеру;
- делает бэкап;
- пересобирает `data/products.js` и SEO-цифры, включая «Более N продуктов» и lastmod в `sitemap.xml`;
- прогоняет тесты и браузерную проверку;
- если что-то не так, откатывается из бэкапа, иначе делает commit и push.

```
python3 tools/auto/daily_add.py --dry-run      # что будет добавлено
python3 tools/auto/daily_add.py --live-check   # добавить, опубликовать и проверить живой сайт
```
